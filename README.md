# aharo.bot

Website for AhaRo, the personal teachable assistive robot by Intellectus Agens.

- `index.html`: the page (all CSS and JS inline)
- `img/`: robot renders, WebP. Replace these with photos, keeping the file names:
  - `hero.webp` (hero, arm reaching toward the text), `teach_show.webp`, `teach_ask.webp`, `teach_trust.webp`, `side.webp` (the five teaching steps; `hero.webp` is reused for "You correct")
  - `anatomy.webp` (front view with numbered pins; 600 x 1100, robot centred)
  - `d_head.webp`, `d_gripper.webp`, `d_carriage.webp`, `d_base.webp` (zoom crops, shown square)
- `fonts/`: Juana (Latinotype) subsets, weights 400 and 500 plus italic
- `brand/`: Intellectus Agens logos, favicon and touch icon
- `og.png`: link-preview image (1200 x 630)
- `CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml`: GitHub Pages plumbing

Hosted with GitHub Pages from the `main` branch, root folder.
