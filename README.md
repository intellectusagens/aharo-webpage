# aharo.bot

Website for AhaRo, the personal teachable assistive robot by Intellectus Agens.

- `index.html`: the whole site in one file (images and the Juana webfont are embedded as data URIs).
- `og.png`: link-preview image referenced from the page's Open Graph tags.
- `CNAME`: custom domain for GitHub Pages.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.

Hosted with GitHub Pages from the `main` branch, root folder.
